## D1. Окружение
1. `git pull`, `npm ci`, `npm run build`, `cd backend && python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && cp .env.example .env`; в `.env` ключи Sandbox (возьми у Даниила, **в репозиторий и в чат не вставлять**), `MONITOR_INTERVAL_SECONDS=10`, `INBOUND_EMAIL_SECRET=<любая строка>` для проверки писем.
2. `uvicorn app.main:app --port 8000`, `python scripts/scenarios.py --links` создаёт счета Sandbox для проверки (сценарий 6 теперь «Premium Antivirus Renewal»), `POST /monitoring/sync` подтягивает их в Monitor.
3. Chrome → `chrome://extensions` → Developer mode → Load unpacked → `dist/`.
**Готово, когда:** панель открывается, вкладка Monitor показывает данные из бэкенда.

## D2. Ручной прогон в Chrome (QA)
Пройти по списку и записывать всё необычное; **не чинить сразу**, сначала список (формат внизу), чтобы Даниил расставил приоритеты.
- **Check** на странице плательщика (`…/invoice/p/#<id>`): кнопка «Check this PayPal invoice», результат, группы находок, сравнение, источник проверки.
- **Check this email**: письмо открыто в Developer Dashboard (Testing Tools → Sandbox notifications), кнопка читает только письмо, секрет вводится в Settings; результат понятен.
- **History:** строки появляются, открытие записи, повтор проверки обновляет запись, поиск, фильтры, сортировка.
- **Monitor:** Overview (плитки, события, Pause/Resume/Sync), Alerts (список, прочитанные, «Open this check» открывает нужную проверку в History), Report (месяц, сохранение, пустой месяц говорит, что данных нет).
- **Settings:** Alert rules (порог, категории), тема, Inbound secret не показывается в открытом виде.
- **Chat:** ответ приходит, при выключенном ИИ сообщение понятное.
- Везде: светлая и тёмная тема; ширина панели 280 / 360 / 480 px; клавиатура (Tab, Enter, Esc); консоль браузера без красных ошибок; нет текста вида «undefined», «NaN», «[object Object]»; формулировки «признаки», не «мошенничество»; нигде не торчат фиктивные данные.
**Формат бага:** `экран → шаги → что ожидал → что получил → скриншот → тема/ширина`. Список отправь Даниилу в чат одним сообщением.
