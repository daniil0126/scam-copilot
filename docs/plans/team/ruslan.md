# Руслан: AI, тесты, безопасность, документация, алерты

**Подпланы:** 07, 13, backend-части 10 и 12. Правила команды: [WORKFLOW.md](WORKFLOW.md). (Если вы с Адилем поменялись ролями, файлы переставьте.)

## Ответственность
- AI-объяснения и чат по инвойсу (`llm.py`, `chat.py`), защита от prompt injection.
- Тестовый набор, метрики Precision/Recall/FPR, калибровка порогов вместе с Адилем.
- Безопасность и аудит-лог, README и материалы для подачи.
- Алерты (backend): категории, пороги, дедупликация, интерфейс каналов. Месячный отчёт (SQL-агрегаты).

## Старт без ожидания других
1. [ ] Тестовый набор `backend/tests/dataset/` в формате `Invoice` из контракта: 20–30 нормальных, 10–15 подозрительных, дубликаты, смена поставщика, необычные суммы, недостаток данных. У каждого ожидаемая классификация и описание.
2. [ ] Скрипт оценки: считает метрики на реальном прогоне, ничего не хардкодит.
3. [ ] Тесты prompt injection на заглушке провайдера.

## Правила
- Ключи только в `.env`, не в репозитории. Не логировать токены.
- Метрики и цифры в документации берутся из реального прогона.
- Файлы моделей/миграций для таблиц алертов согласуйте с Даниилом (PR вместе с его схемой).

## Готово, когда
Метрики посчитаны и записаны, инъекции не влияют на результат, High/Critical даёт ровно одно уведомление.
