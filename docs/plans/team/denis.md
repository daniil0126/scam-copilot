## Задачи
| Этап | Задачи |
|---|---|
| 1 | Каркас вкладки, выбор периода (7/30/90/custom), таблица с колонками из ТЗ, сортировка, фильтры, поиск, сводка |
| 2 | Состояния: Loading, Empty, API Error, Partial Results, Analysis Failed (ошибка строки не блокирует таблицу) |
| 3 | Карточка инвойса: данные, score, level, confidence, сигналы с evidence и источником, история, рекомендации, AI-объяснение |
| 4 | CSV (с учётом фильтров, защита от формул `= + - @`), дашборд мониторинга: Pause/Resume, Sync, пороги, ошибки, уведомления |
| 5 | Месячный отчёт, доводка дизайна, проверка в браузере |

## Правила интерфейса
- Формулировки «обнаружены признаки», «требует проверки», не «мошенник».
- Нет захардкоженных результатов, выдаваемых за реальные.
- Проверки: `npx tsc -b`, `eslint`, ручной прогон в Chrome.

## Готово, когда
Аудит из реального backend виден в таблице, строка открывает карточку, CSV совпадает с отфильтрованными данными.
