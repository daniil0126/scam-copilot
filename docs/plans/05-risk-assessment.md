# 05. Risk Assessment

**Приоритет:** P0. **Раздел ТЗ:** 6. **Зависит от:** 04.

## Цель
Единый механизм итогового результата: score, level, confidence, сигналы, доказательства, рекомендации.

## Задачи
- [ ] Выход: `invoiceId, riskScore 0–100, riskLevel (LOW 0–29, MEDIUM 30–59, HIGH 60–79, CRITICAL 80–100), confidence (LOW/MEDIUM/HIGH), signals, recommendations, engineVersion`.
- [ ] **Score и Confidence считаются раздельно.** Confidence зависит от полноты полей и объёма истории, не от тяжести сигналов.
- [ ] Агрегация без механического суммирования: сигналы группируются по семейству (коррелирующие дают убывающий вклад, например max + затухающая добавка).
- [ ] Неизвестные поля и `INSUFFICIENT_DATA` не меняют score, но снижают confidence и показываются явно.
- [ ] Рекомендации строятся из типов сигналов по шаблонам (без AI), только анализ и предупреждение, без действий над деньгами.
- [ ] Пороги уровней в конфиге; помечены как начальные, калибруются в плане 13.
- [ ] Адаптация существующего `scoring.py`, а не параллельный модуль.

## Тесты
Одиночные сигналы, коррелирующие сигналы (проверка убывающего вклада), пустая история (низкий confidence, score не растёт), граничные значения порогов.

## Готово, когда
Любой score можно разложить на сигналы с evidence; формат совпадает с примером из ТЗ.
